# Working in this repository

Read this before changing anything under `agent_economics/`.

## The one invariant

**A missing gate is not a passing gate.** If any dimension of the fixed required
coverage is absent, disabled, or unsatisfied, `INCOMPLETE` is the only legal
verdict. Every other property here is negotiable; this one is the product.

Concretely, a change is wrong if it lets required coverage be derived from
whichever checks happen to be enabled, rather than read from the pinned
contract. That is the exact failure the repository exists to demonstrate, and
`make mutation` measures it: the fixed-contract kill rate must stay at 100%.

Only `SCALE` may exit 0. `INCOMPLETE` is 2, `ASSIST` is 3, `STOP` is 4.

## Never regenerate a fixture to make a comparison pass

Several targets byte-compare generated output against a committed artifact
(`research/results/`, `examples/*/bundle.json`, `research/SELF_AUDIT.md`). When
one of those comparisons fails, exactly one of two things is true: the engine
changed, or the artifact is stale. Those are different problems with different
fixes. Regenerating to get a green build converts a real finding into a silent
one, which is the failure mode this project is about.

## Published numbers need a mechanism, not care

Every measured result in `README.md` is guarded by a literal assertion in
`tests/` or a byte-comparison against a committed artifact. If you publish a new
number, guard it in the same commit.

A hand-typed copy of a computed value is an unguarded claim. It will not fail
when it goes wrong; it will drift. `research/SELF_AUDIT.md` is generated by
`research/self_audit.py` from git and live runs for exactly this reason, after
five rounds of hand-correcting numbers that kept going stale.
`research/SELF_AUDIT.md` documents that episode.

## Running things

The package requires Python 3.10 or newer and `make` refuses to run below it. If
your default `python3` is older, pass the interpreter:

```bash
make reproduce PYTHON=python3.12
```

`make reproduce` is the whole contract: tests, both ablation benchmarks, the
mutation score, the frontier, every adapter, and every byte-comparison. It is
what CI runs. `make lint` needs the dev extra (`pip install -e '.[dev]'`).

Zero runtime dependencies, deliberately. Adding one requires an issue explaining
why the assurance claim cannot be made without it.

## Reviewing

Three agent definitions live in `.claude/agents/` and are worth using:

- `contract-invariant-guard` on any diff touching the decision path
- `claims-auditor` before publishing or releasing
- `repro-drift-check` when a byte-comparison fails and you need the target isolated

They were written after all three found real defects in this repository, and
they still do.

## Language

Precision here is load-bearing, because the claims are the product:

- **structural repetition warning**, not semantic-loop proof
- **dependency cycle**, not deadlock, absent wait/progress semantics
- **no additional model inference**, not zero compute
- **observed association**, not causal savings, without a valid design
- always name the population, the observation window, and the counterfactual

Never commit customer data, account identifiers, real prompts, or contract
pricing. Aggregate, redact, or synthesize first.
